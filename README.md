# Development Workstation Tools and Configuration

My latest terminal-native agent-first workstation setup.

Minimize distractions and parallelize agentic workflows.

## Current Set of Tools

- WezTerm
- zsh & oh-my-zsh
- tmux
- NeoVim
- Codex
- fzf
- RipGrep
- LazyGit - for visual git tasks
- RevDiff - for providing PR style feedback on agent produced diffs

### Custom Utilities

- Delegator - Used for quickly spinning up a fresh tmux session and git worktree for parallelizing agent tasks.
- Codex Agents - Live terminal dashboard for Codex session and subagent status.
